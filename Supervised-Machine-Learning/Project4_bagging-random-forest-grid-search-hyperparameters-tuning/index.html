🇫🇷 Présentation du projet

Ce projet applique des techniques d'ensemble, notamment le bagging et les forêts aléatoires, afin de déterminer si le patient a ou non un problème au foie. L’objectif est d’améliorer la précision des prédictions en comparant plusieurs modèles et en optimisant leurs hyperparamètres via une Grid Search. L’évaluation des performances se fait à l’aide de plusieurs métriques.

🇬🇧 Project Overview

This project applies ensemble learning techniques, including bagging and random forests, to determine whether a patient has a liver condition or not. The objective is to improve prediction accuracy by comparing several models and optimizing their hyperparameters using grid search. Model performance is evaluated using multiple metrics.
